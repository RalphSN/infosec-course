# 資訊安全風險與防護工程

給零基礎學習者的一套完整互動式資安課程，共 18 課、5 個階段，全部在一個自足的 HTML 頁面裡。

**線上閱讀（GitHub Pages）**：啟用 Pages 後網址會是 `https://<你的帳號>.github.io/infosec-course/`

## 課程內容

| 階段 | 課程 |
|---|---|
| 一 · 安全思維 | 01 全景地圖、02 風險的算術、03 威脅建模 |
| 二 · 信任的基石 | 04 密碼學直覺、05 信任的鏈條、06 身分驗證、07 授權與存取控制 |
| 三 · 應用程式攻防 | 08 注入攻擊、09 瀏覽器戰場、10 供應鏈與設定錯誤、11 AI 系統安全、12 安全開發生命週期 |
| 四 · 系統、雲端與應變 | 13 縱深防禦與零信任、14 雲端安全、15 偵測與監控、16 事件應變與韌性 |
| 五 · 人與總整合 | 17 人與治理（含台灣法規）、18 總整合專題 |

## 特色

- 30 多個互動元件：即時計算的 SHA-256 雪崩、Diffie-Hellman 混色、TLS 交握、SQL 注入模擬、3D 相依關係圖、AI 提示詞注入沙盒、勒索軟體桌上演練、可匯出的總整合風險工作表等。
- 每題都能「先想再看答案」，答不順的自動進入 1／3／7／14 天間隔複習佇列。
- 深淺色主題、專注模式、手機版皆已支援。
- 學習進度存在瀏覽器本機（localStorage），不會上傳。

## 技術說明

- 單一 `index.html`，原生 JavaScript，無需建置步驟。
- 字型來自 Google Fonts；第 10、13 課的 3D 圖解需要網路載入 Three.js（cdnjs），離線時自動改用 2D 版。
- 內容以 2026 年 9 月的標準與法規為準。
